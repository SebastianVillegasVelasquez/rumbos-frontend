Rumbos — mock host (Moodle plugin stand-in, dev only)

This page plays the role of the format_rumbos plugin: it embeds the app in an iframe, answers the handshake with a fake assertion and serves a configurable CourseState. Run the app with VITE_USE_MOCK_API=true. To exercise real cross-origin checks, open this page on 127.0.0.1 and the app on localhost (or the other way round).
